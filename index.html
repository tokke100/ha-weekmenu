Nog geen weekmenu

Open een terminal in deze map en voer uit:

node weekmenu.js

Daarna deze pagina vernieuwen. Of start de server (node weekmenu.js --server) om het menu vanuit de pagina te maken.

Klik op Nieuw menu… bovenaan.
